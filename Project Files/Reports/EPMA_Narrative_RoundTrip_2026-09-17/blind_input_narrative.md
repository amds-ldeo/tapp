# Documenting an Electron Probe Microanalysis Procedure

A properly documented electron probe microanalysis (EPMA) procedure is made of two records. The first is the procedure: the standing recipe, written once, registered, and cited from then on by its DOI. The second is the record of an analytical session that followed the procedure. One session record covers one session, and one session can cover several samples.

Each item in this guide is assigned to one or both records according to a single set of principles. An item belongs to the procedure when it can be decided before any analysis is run, and belongs to the session alone when its value can only be known once the session has taken place — who ran it and when, what was analysed, and every measured outcome. In the procedure record, *must* means the procedure cannot be registered without the item, and *should* means the item is strongly recommended but may be left out. What the procedure states then reaches the session in one of two ways. It is *fixed* when it defines the procedure itself — the instrument and its hardware, the choice of method or algorithm, and the lists of what is measured and reported; a session that changes a fixed value is running a different procedure. It *may be adjusted* when it is a setting or choice that legitimately varies between sessions within the bounds the procedure allows — operating conditions tuned on the day, software versions, criteria applied to the material at hand, reference materials that run out and must be replaced; the session then records the value it actually used. For items that belong to the session alone, *must* means the session record is incomplete without the item and *should* means it is recommended. Where the procedure gives a typical or target value and the session reports the value it obtained, both are stated. Finally, an item is reported once for each thing it varies over — once per session, per sample, per analysis point, per element, per reported quantity, or per reference material — and the text states which.

EPMA procedures run in one or more of four modes: point analysis by energy-dispersive spectrometry (EDS), X-ray mapping by EDS, point analysis by wavelength-dispersive spectrometry (WDS), and X-ray mapping by WDS. Most of what follows applies to all four. Where something applies only to some modes, the guide says so, and a procedure only needs to report those items for the modes it uses.

The procedure must have a short descriptive name with a version number that identifies the instrument, the technique, and the scope of what the procedure measures. It must state whether it uses WDS, EDS or both. It must name its author, a person or a laboratory, with an ORCID recommended for a person, and must name the laboratory or institution that hosts the instrument. It should give that laboratory's persistent identifier. The laboratory and its identifier may be adjusted by a session. The procedure must give the date its configuration first went into production use. It should name the funding that supported the instrument, major upgrades and the development of the procedure, with agencies and grant numbers, and should cite the publications or technical reports that describe, validate or benchmark it. The author, name, technique, start date, development funding and references are fixed.

Each session must cite the DOI of the procedure it followed, or state "pending" if a DOI has been applied for but not yet issued. It must give the laboratory's own identifier for the session, as generated by the instrument or acquisition software. It must name the analyst or analysts, with ORCIDs recommended. It must give the date the session began and the date it ended, and must name the funding that supported these specific analyses, with agencies and grant numbers.

The procedure should name any other techniques applied to the same samples whose results are meant to be interpreted together with these, naming the instrument, laboratory or purpose of each, or state "None". It should describe the coupling in two parts: what data or context passes between the techniques, and which technique is performed first and why. The description is required whenever a coupled technique is named. A session may adjust both. Each session should give the registered procedure DOI of the coupled technique, or the DOI of a publication describing it, or "pending", or "None". It should also give the persistent identifier of the dataset or publication where the coupled datasets are reported together, or "same submission", or "pending". Where the coupling is documented only through a shared sample identifier, the sample identifier suffices.

The procedure must state the material types it is designed to analyse; these are fixed. It must describe the form in which samples are presented to the instrument and the preparation that brought them to that form, or state "None" where material is analysed as received; a session may adjust this. The procedure must state what kind of subdivision of a sample one row of reported results corresponds to, giving both levels where such units nest; this is fixed. It must state the criteria by which the units analysed are selected within a sample; a session may adjust these.

Each session must list every sample it analysed, under the name the laboratory uses for it. A mount, section or aliquot counts as one sample where that is what the laboratory tracks, and the names should match those used in the associated publications and data tables. For each sample, the session must list the units it analysed, using the laboratory's own labels. Where the units are too numerous to name individually, the session names the acquisition area they belong to instead. For each sample, the session should give a globally unique persistent identifier, with IGSN the recommended standard, at the level actually analysed. The procedure should describe any imaging or screening performed before analysis to locate and select the units analysed, including the technique, instrument and settings, and how individual analyses are linked back to the images. For each sample, a session may adjust this. Where that imaging is performed on a separate instrument, it should also be recorded among the coupled techniques.

The procedure must identify the instrument by manufacturer and by model, including any generation or configuration suffix, and must state the type of electron source. These are fixed. It must name the software that controls the instrument and acquires the data, and every software package applied to the data after acquisition to produce the reported values, with version numbers. A session may adjust both. Where WDS is used, the procedure should describe the number, type and crystal range of the WDS spectrometers, with manufacturer and model. Where EDS is used, it should describe the detector type, manufacturer, number of detector elements, active area and solid angle, window type, and geometry, listing multiple detectors separately. Both are fixed.

The procedure must declare which of the four modes it covers, listing all that apply; this is fixed. It must state the accelerating voltage in kilovolts and justify any departure from the laboratory's standard operating voltage; a session may adjust it. Beam conditions are reported for each analysis point within each sample. The procedure must state the beam mode, and this is fixed. It must state the beam current in nanoamperes and the beam diameter in micrometres, and a session may adjust both. In point analysis by either EDS or WDS, where the beam is rastered, the procedure should give the width and height of the rastered area in micrometres, which a session may adjust. Beam mode, diameter and raster dimensions must be consistent with one another. The procedure should describe the measures taken to minimise beam damage, including the beam conditions used and the phases to which they are applied, and a session may adjust them. The procedure should also describe how drift in beam current and spectrometer position is monitored and corrected during a session; a session may adjust this.

The procedure rests on three separate lists. The first is the elements the procedure determines. The procedure must give it, and a session may adjust it to the narrower suite actually measured. Isotopes are never separate entries. The second is the elements monitored in order to make those determinations. The procedure must give it, grouping each monitored element under the determined element it serves, and including elements monitored only to correct an interference, which serve none. This list is fixed, and neither list is inferred from the other. The third is the quantities the procedure finally reports, with their units, including any intermediate quantities reported alongside final ones. The procedure must give it, and it is fixed.

For each determined element, where a procedure uses both WDS and EDS, the procedure must state which of the two measures it. This is fixed.

For each monitored element, the procedure must state the X-ray emission line measured. This is fixed. In WDS work, in both point analysis and mapping, the following are also fixed for each monitored element. The procedure must state the diffracting crystal. It should state the spectrometer position or positions the element is assigned to, one entry per assignment, including an element assigned to more than one spectrometer with the intensities aggregated. It should state the detector type and the pulse height analyser mode.

In WDS point analysis only, the procedure should state for each monitored element the order in which it is acquired and, where the element suite exceeds the number of spectrometers, the acquisition pass to which it belongs; this is fixed. The procedure must give each monitored element's on-peak counting time in seconds and its total off-peak background counting time in seconds, summed across all background positions. It should state the location of each background position relative to the peak, in millimetres or sin θ and on the high- or low-energy side, or state that no off-peak positions are used. A session may adjust counting times and background positions.

In EDS work, the procedure must state how the beam is positioned during EDS acquisition, listing all approaches that are used; this is fixed. In EDS point analysis, the procedure must give the live time per analysis point in seconds, which a session may adjust.

In X-ray mapping by either EDS or WDS, the procedure must give the dwell time per pixel for each monitored element — one value per spectrometer assignment for WDS, and a single live time per pixel for EDS — and the step size in micrometres, with X and Y given separately where they differ. A session may adjust both. Each session must record the map dimensions in pixels and the physical extent of the mapped area. The procedure should state whether maps are acquired by stage scan or beam scan; this is fixed.

The procedure must name the matrix correction algorithm, which also applies when count maps are converted to concentration maps, and the database of mass absorption coefficients the correction uses. Both are fixed. The source of the calibration constants is reported separately, under calibration. For each monitored element, in every mode, the procedure must state how the background beneath the peak is estimated and subtracted; a session may adjust this.

For each determined element, the procedure should state any time-dependent intensity correction applied, which a session may adjust, and should state how its concentration is obtained from the measured data, which is fixed. The procedure should state whether oxygen is adjusted for halogen substitution where oxygen is calculated by stoichiometry; a session may adjust this. Where WDS is used, the procedure must state the dead-time correction algorithm and any instrument-specific constant; this is fixed, and no measured WDS dead time is reported. Where EDS is used, the procedure should state how net peak intensities are extracted from the spectra before quantification; this is fixed.

For each determined element, the procedure should state the method and reference material used to determine and subtract a blank, which a session may adjust, and each session must report the blank level it measured, together with the blank's composition where the reported quantity is a ratio. For each reported quantity, the procedure should state any normalisation applied beyond the primary calibration, or "None". For each reported quantity, the procedure must give any externally calibrated factor that converts the measured quantity into the reported quantity, how that factor was determined, and its uncertainty. A session may adjust both.

The procedure must state the rules that decide which individual results contribute to a reported aggregate value, where an individual result is the value obtained from one acquisition — whichever unit the procedure aggregates. Each session must report the outcome of applying them: how many results were obtained, how many were included, and on what grounds any were excluded. These rules concern finished results, not the filtering of acquired signal during data reduction. The procedure must list the physical constants and citable reference values used in data reduction, with their sources, or state "None"; a session may adjust this. Accepted values of specific reference materials are reported with those materials, not here.

For each determined element, the procedure must name the primary reference material against which the instrument is calibrated, its source or supplier, and a citation for the accepted values used. Where quantification uses a stored library or response model instead, the procedure names it; "None" means no calibration was performed. The procedure must list the secondary reference materials measured as unknowns alongside the samples, with the source of each and a citation for its accepted values. A session may adjust both.

For each determined element, the procedure must state whether an X-ray line overlap correction is applied and, if so, the overlapping lines and the correction method. For each determined element, it should name the interfering elements whose lines overlap the measured peak, and the reference material used to calibrate the interference correction. All of these are fixed.

For each reported quantity, the procedure must state the formula or approach used to calculate the detection limit, with a citation where one exists; this is fixed. For each reported quantity, the procedure should give detection limits and each session must report them, with units, stating whether the values are typical estimates or session-specific measurements and consistent with the stated method. For each secondary reference material, and for each reported quantity, the procedure should give and each session must report the analytical precision, as a one-sigma relative standard deviation in percent with the number of analyses and the measured value, and the analytical accuracy, as a percent relative bias with the source of the accepted value.

Within each sample, for each analysis point, and for each reported quantity, the procedure should give and each session must report the uncertainty predicted from counting statistics, including the counts on any background or blank subtracted, with the sigma level stated. This is reported separately from any observed scatter between measurements. In EDS work, each session must report the percent dead time recorded by the detector. For each reported quantity, each session must report the statistic used to assess whether scatter among the contributing individual results exceeds what analytical uncertainty alone predicts, together with its value; any acceptance threshold is stated with the inclusion rules. Finally, the procedure and the session should each record any information not captured elsewhere in this guide, including anomalies, deviations from the registered procedure and instrument modifications.
